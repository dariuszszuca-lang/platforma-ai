CEO Core — Centrum Dowodzenia

Jak wywołać

/ceo lub opisz złożony problem — CEO sam rozłoży na zespół

Co robi

  • Analizuje zadanie i deleguje do odpowiedniego asystenta
  • Koordynuje pracę kilku asystentów naraz
  • Planowanie kwartalne, OKR-y, trudne decyzje
  • Synteza odpowiedzi z całego zespołu

Przykładowy workflow

Ty: "Mam za dużo na głowie, nie wiem od czego zacząć" CEO analizuje sytuację → deleguje do COO (plan działania) → deleguje do CSO (szybka kasa) → deleguje do CMO (content na tydzień) → zbiera odpowiedzi i daje Ci 1 plan

COO — Brutalnie Skuteczny Dyrektor Operacyjny

Jak wywołać

/coo — gdy masz chaos, brak czasu, nie wiesz od czego zacząć

Menu COO

  • Plan dnia — konkretny plan z priorytetami na dzisiaj
  • Plan tygodnia — rozkład całego tygodnia

Filozofia

DONE > PERFECT. Zasada 2h: jeżeli zadanie zajmuje mniej niż 2h — rób TERAZ, nie planuj.

CCA — Chief Cloud Architect

Agent Builder — Budowa Agentów AI

Co to jest

System do tworzenia i zarządzania specjalizowanymi agentami AI. Każdy asystent w tym systemie (CEO, COO, CSO...) to agent zbudowany w Agent Builderze.

Elementy systemu

  • Commands (.claude/commands/) — szybkie skróty do wywołania asystenta
  • Skills (.claude/skills/) — 19 specjalizowanych workflow'ów
  • Personality Files (Asystenci-zespół/) — pełne definicje osobowości
  • Agent Teams — tryb wieloagentowy, kilka instancji równolegle
  • MCP Serwery — połączenia z zewnętrznymi narzędziami

Jak zbudować nowego agenta

1. Stwórz plik osobowości w Asystenci-zespół/NAZWA.md (rola, filozofia, menu, protokoły, pliki do czytania) 2. Dodaj command w .claude/commands/nazwa.md (skrót /nazwa → ładuje plik osobowości) 3. Dodaj skill w .claude/skills/nazwa.md (triggery, workflow, format wyjściowy) 4. Zarejestruj w CLAUDE.md (opis roli, granice, kiedy używać) 5. Gotowe — wpisujesz /nazwa i agent działa

Agent Teams (praca równoległa)

Włączone w systemie. Pozwalają uruchomić kilku agentów naraz — np. CMO pisze posty, CSO przygotowuje maile sprzedażowe, a CTO deployuje stronę. Wszystko równolegle.
